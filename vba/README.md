# Outlook Autosave — VBA-версия (устаревшая)

Это исходный макрос версии 1.0.x. Он больше не развивается: актуальная версия — COM-надстройка с установщиком, см. [README](../README.md).

Макрос и надстройка используют одни и те же настройки. Не держите их включенными одновременно, иначе автосохранение будет выполняться дважды.

## Установка

1. Откройте Outlook и нажмите `Alt + F11`.
2. В редакторе VBA импортируйте все `.bas` и `.frm` файлы из этой папки. Рядом с каждым `.frm` должен лежать одноименный `.frx`.
3. В дереве проекта откройте `Microsoft Outlook Objects -> ThisOutlookSession` и вставьте код из `ThisOutlookSession_template.txt`:

   ```vb
   Private Sub Application_Startup()
       AutoSaveStartup
   End Sub
   ```

4. Сохраните проект и перезапустите Outlook.

Макросы: `OutlookAutosave` открывает настройки, `SaveSelectedAttachments` сохраняет вложения из выбранных писем. Их можно вынести на ленту через `Файл -> Параметры -> Настроить ленту -> Макросы`.

## Подпись макроса

Чтобы макрос работал без отключения настроек безопасности Outlook, подпишите его собственным сертификатом. Все действия выполняются от имени пользователя, без прав администратора.

1. Запустите `SelfCert.exe` (обычно `C:\Program Files\Microsoft Office\root\Office16\SELFCERT.EXE`), задайте имя сертификата `Outlook Autosave` и нажмите `ОК`. Сертификат создается на 5 лет.
2. Откройте хранилище сертификатов: `Win + R -> certmgr.msc`.
3. В `Личное -> Сертификаты` найдите созданный сертификат, нажмите по нему правой кнопкой мыши и выберите `Копировать`.
4. Вставьте сертификат в `Доверенные корневые центры сертификации` и `Доверенные издатели`.
5. В Outlook нажмите `Alt + F11`, выберите `Tools -> Digital Signature`, нажмите `Выбрать` и `ОК`.

## Повторный запрос сохранения VbaProject.OTM

После импорта, компиляции или запуска макросов Outlook может при закрытии снова спросить, сохранять ли изменения в `VbaProject.OTM`. Это нормально: Outlook помечает VBA-проект измененным после компиляции, открытия форм или сброса подписи. Если изменения вносились, выбирайте `Да`.

## Файлы

| Файл | Назначение |
| --- | --- |
| `MainModule.bas` | Основная логика сохранения, автосохранения, статуса, таймера и правил |
| `AutoSaveSettingsUi.bas` | Публичные макросы `OutlookAutosave` и `SaveSelectedAttachments` |
| `AutoSaveSettingsForm.frm/.frx` | Главная форма настроек |
| `SelectedSaveSettingsForm.frm/.frx` | Настройки сохранения выбранных писем |
| `SortRulesForm.frm/.frx` | Форма правил сортировки |
| `FolderSelectionForm.frm/.frx` | Выбор исходной папки Outlook |
| `SortRulesSettingsCore.bas`, `SortRulesSettingsUi.bas` | Хранение правил и открытие формы правил |
| `FileTypesForm.frm/.frx`, `FileTypesSettingsCore.bas`, `FileTypesSettingsUi.bas` | Устаревшая настройка типов файлов (не используется в текущем интерфейсе) |
| `ThisOutlookSession_template.txt` | Код для `ThisOutlookSession`; не импортируется как модуль |
